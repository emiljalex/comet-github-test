# comet-github-test

This repository contains a simple test webpage used to verify GitHub workflows (branching, commits, and pull requests).

## Test Webpage

The `index.html` file on the `test-webpage` branch contains a minimal, self-contained HTML page titled "Comet GitHub Test". It includes:

- A heading and short paragraph describing the page
- A button that, when clicked, changes the paragraph text using inline JavaScript
- All CSS and JavaScript embedded directly in the HTML file (no external dependencies)

This page is intended purely as a test artifact to confirm that file creation, branching, and pull request workflows function correctly in this repository.
